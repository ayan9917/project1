# Dementia Memory Game

A simple offline browser game designed as a memory/cognitive exercise prototype.

## Features
- Shows an image for a limited number of seconds.
- Hides the image automatically.
- Provides multiple image choices.
- Correct answer increases score.
- 3 wrong answers end the game.
- Difficulty increases with level.
- Viewing time becomes shorter at higher levels.
- Number of choices increases at higher levels.
- Works offline; no server or installation required.
- Responsive design for laptop/mobile browser.

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Click "New Game" whenever you want to restart.

## Important
This is a prototype/game and is not a medical diagnostic or treatment tool.
